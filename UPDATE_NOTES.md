# Instant Messaging App Updates

## Recent Changes
- Fixed UI rendering issues in MessagingHub component
- Improved navigation with restored Navbar
- Enhanced visual design with consistent styling
- Separated Channels and Direct Messages interfaces
- Renamed sections to follow specifications
- Improved error handling for message operations

## Known Issues
- Some functionality is still experimental
- Channel creation is currently disabled
- Message deletion functionality may be unstable

## For a stable version
Check commit history for more stable versions or use the main branch.

## Getting Started
Run the backend: `cd backend && npm run dev`
Run the frontend: `cd frontend && npm start`
